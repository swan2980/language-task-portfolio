模块二LLM Prompt 构建与输出纠偏

任务类型：Prompt 编写 + 输出校对 + 情绪 / 意图 / 风格标注
起点：在使用大模型协助编辑时，观察到模型常无法保留原句的情绪质感与风格语调，输出「太工具化」或「太模糊」。于是反复调整输入结构、记录有效与无效的触发模式，逐步形成对模型语言偏差的识别感。

我有时候觉得不是我不想说，是说的那个回路根本没打开。 用生理隐喻模拟「表达系统未激活」的内在体验 我有点不愿意表达，可能是不想面对问题。 用「回避」替代了「表达机制失效」；忽略回路隐喻；风格单调 像是有人偷偷把那个「开口的按钮」藏了起来，我一直在找，但没有反应。 沉默、冻结、轻微困惑
风格：身体化语言 / 神经断路隐喻
我认为自己不能忍受他人用审视的方式看我，哪怕他们说的是好话。 表达「被称赞时的不适感」，强调被凝视的不自由，不使用否定式 我不喜欢别人夸我，这让我觉得很别扭。 情绪标签粗糙（「别扭」太轻）；未呈现「赞美即控制」；缺少文化 / 关系隐喻层 他们说我是个值得被喜欢的人，我笑着点头，但心里像被什么捏了一下。 羞耻、被凝视、控制下的顺从
风格：隐性抵抗 / 多义性表达

能力体现

  • 能构建 Prompt 指令、识别模型输出问题、完成校对与风格调整，同时完成语言结构标注
  • 将 Prompt 编排与输出评估标准化，形成适用于「风格重建 / 语义纠偏 / 结构提炼」的语言调控能力
这份能力的来源不是课程，而是长期使用中积累的「生成语言判断力」—— 从语言使用者转向语言建模参与者的关键一步。

模块四ASR 评测实战：Whisper 在粤语字表朗读场景的适用性

数据：粤语田野调查录音《江曾摄》408 秒；《江摄》字表 54 条，其中 41 条成功采集读音，13 条因发音人无法引导而缺失（评测中整行剔除，避免虚增漏识）
系统：Whisper small（faster-whisper 1.2.1，int8 量化，language=zh）
方法：VAD 分段 → 逐段转写 → 与字表对齐 → 双口径 CER 计算 → 音系错误归因

三个发现

1
输出多样性塌缩
41 条参考字涵盖 20 种不同音节、10 类声母（p / pʰ / ʦ / ʦʰ / s / k / h / m / t / ŋ）；模型在该区间输出的 58 个单元中，43 个是同一个字「膀」，去重后仅 6 种。本应呈现明显差异的音节序列，被压成单一字形。
2
同音字归并，导致字面 CER 系统性虚高
字表「邦」→ 输出「帮」（bong1 / bong1）、「庞」→「旁」（pong4 / pong4）、「窗」→「枪」（coeng1 / coeng1）：字面全错，音值全对。方言调查按「音」列字，同一个音底下一组同音字，模型只保留一个字形，因此仅用汉字错误率会严重高估错误。
3
通用粤拼词表不适用于本方言点
字表记「江 / 扛 / 豇」均为 kɔŋ 51（见母读 k-），而标准粤拼为 gong1（g-）。以通用词典作判定基准，会把本来正确的判成错误 —— 评测基准必须使用田野采集的 IPA 记音。

方法建议：双口径 CER 框架

口径计算方式用途
字面 CER严格按汉字比对（编辑距离 ÷ 参考字数）与行业常规指标对齐
音值 CER同音字判为正确，只计真音错反映实际可用性

两个口径的差值 = 同音字归并造成的假错误比例。错误再按声母 / 韵母 / 声调 / 增字 / 漏识细分归因。

局限（如实说明）

  • 逐段对应关系尚未逐条人工复核，结论基于序列整体统计
  • 样本为单一方言点、单一发音人，不可外推至粤语整体
  • 未做参数对比实验（model size、language=zh / yue）
该模块的核心价值：识别出「字面错、音值对」这一只有语言学背景才能发现的评测陷阱，并据此提出双口径评测方案。
